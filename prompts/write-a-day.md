# Brief: write one day

Paste this into a Claude Code session in the repo, with the day filled in.

```text
Write the chapter for Day N, <place>, following STYLE.md.

- Read STYLE.md and one finished day chapter first, so this one matches.
- Use SKELETON.md only to know what the day contains. Copy nothing else from it: no dates, no bookings, no names.
- Find the facts on the web. Every fact goes with its source at the end; mark commercial and tourism sources.
  If two sources disagree, say so in the text with careful wording instead of picking one.
- Five phrases for the day, script · romanisation · meaning, things I could say that day.
- Suggest one plate (a drawing that explains something better than a paragraph). Describe it; don't draw it yet.
- Write it as book/OEBPS/day-N-<place>.xhtml and wire it into content.opf, nav.xhtml, toc.ncx and the index
  in 02-the-days.xhtml.
- Build the EPUB. Done = the chapter reads well out loud, every fact has a source, the EPUB builds.
```
